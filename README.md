# Прямые продажи для продавцов Wildberries

Статический лендинг для услуги запуска собственного интернет-магазина и привлечения покупателей из Яндекс Директа.

## Важно

- блоки «модели запуска» — расчётные сценарии, а не результаты конкретных клиентов;
- форма в текущей версии демонстрационная и требует подключения обработчика заявок перед боевым запуском.
